
# Glow Beauty Salon & Spa

A beauty salon website that helps customers book appointments online.

## About the Project
Glow Beauty Salon & Spa is a website developed to manage salon appointments. Customers can book appointments, and the admin can view and manage bookings.

## Technologies Used
- HTML
- CSS
- PHP
- MySQL

## Features
- Online appointment booking
- Appointment details stored in MySQL
- Admin login
- Admin dashboard to view bookings
- Appointment cancellation

## How to Run the Project
1. Install XAMPP.
2. Copy the project folder into `htdocs`.
3. Start Apache and MySQL.
4. Create a database named `glow_salon`.
5. Import the project database SQL file.
6. Update the database connection settings in `database.php`.
7. Open `http://localhost/BeautyParlourWebsite/` in your browser.
